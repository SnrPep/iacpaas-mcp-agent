# Словарь

| Термин | Значение |
|---|---|
| IACPaaS | облачная платформа ИАПУ ДВО РАН для интеллектуальных систем на онтологиях (iacpaas.dvo.ru) |
| Фонд / «Мой Фонд» | хранилище платформы; личный фонд пользователя |
| Инфоресурс (ИР) | единица хранения с информацией: БЗ, БД, онтология. Логически — граф |
| Метаинформация / онтология | ИР, описывающий структуру другого ИР: какие понятия, сколько, как связаны |
| Вершина (понятие) | узел графа: КОРЕНЬ, НЕТЕРМИНАЛ, ТЕРМИНАЛ-СОРТ, ТЕРМИНАЛ-ЗНАЧЕНИЕ |
| Дуга (отношение) | ребро графа |
| Метавершина (`meta`) | понятие онтологии, по образцу которого создана вершина |
| Спецификатор | сколько потомков: один, ноль или один, список, множество… |
| Ограничитель | как порождается потомок: новая вершина, ссылка, клон |
| Ссылка (`link`) | дуга на уже существующую вершину (этого или другого ИР) |
| Путь ИР | `папка/Имя ИР` внутри «Мой Фонд» (полная форма: `e-mail/Мой Фонд/папка/Имя ИР$;`) |
| Путь вершины | метки от корня через `/`; метку с `/` обрамляют `‴…‴` |
| MCP | Model Context Protocol — стандарт подключения ИИ-приложений к внешним системам |
| MCP-сервер / клиент / хост | поставщик инструментов / соединение с сервером / приложение с моделью |
| Инструмент (tool) | функция, которую модель может попросить вызвать; описана JSON Schema |
| stdio / Streamable HTTP | транспорты MCP: подпроцесс / веб-сервис с одним адресом `/mcp` |
| Bearer-токен | секрет в заголовке `Authorization: Bearer …` (здесь — `MCP_BEARER_TOKEN`) |
| Агент | программа, которая в цикле даёт модели думать, вызывать инструменты и читать результаты (ReAct) |
| HITL | human-in-the-loop — подтверждение человеком перед опасным действием |
| confirm_token | одноразовый токен подтверждения записи (HMAC от операции и аргументов, 5 минут) |
| Песочница (mock) | локальная копия ИР из `fixtures/`; платформа не затрагивается |
| Трасса | журнал шагов агента (`logs/agent_trace.jsonl`) |
| Чекпоинтер | хранилище состояния диалогов LangGraph (`data/agent.sqlite`) |
