# Проверка точности агента

Инструкция — `config/agent_prompt.md` (для VS Code — сокращённая версия в `.github/agents/iacpaas.agent.md`).
Данные — ИР подгруппы на реальной платформе (тема «Технологические газы», только чтение). Эталоны посчитаны из
выгрузки данных напрямую, 14.10.2026. История настройки инструкции — `docs/dev-log.md`.

## Как проверяем
```
вопрос ──> настоящий агент (модель → LangChain → MCP-сервер → IACPaaS REST, только чтение)
                 │ каждый вопрос — отдельный диалог, отдельная БД data/eval.sqlite
                 ▼
logs/agent_eval_<модель>.jsonl (вызовы, ответ, время) ──сверка вручную──> эталон ниже
```
Запуск: `.venv\Scripts\python scripts\agent_eval.py --model gigachat` (все) или с номерами (`A3 D4`).

### Версия 4: стенд на 124 вопроса
В версии 4 о газах отвечает код (`gas_query`), модель выбирает запрос; поэтому проверяется не текст, а то, что
посчитано и показано. Стенд – `scripts\agent_bench.py --base tests\snapshot --model gigachat` (снимок базы).
Вопросы S, T, Q и диалоги D, D2 – все типы из
`docs/questions.md`: списки, «без / кроме», пороги, самый / хуже / лучше со всеми равными, top-N, сортировка,
сравнение, общие примеси, ошибки состава, смеси, расчёты, уточнения по истории, платформа, запись, «не о базе».
Ожидаемое у каждого вопроса посчитано кодом из снимка базы; ответ засчитан, если совпали газы и числа и нет пометок
проверки.
