## Версия 4 (текущая): VS Code, консоль, веб-чат — реальная платформа
Подготовка VS Code: `.venv\Scripts\python scripts\setup_clients.py` (пишет `.mcp.json`) → открыть папку проекта.
Claude Code – подтвердить сервер `iacpaas` (`/mcp`); Copilot – чат в режиме **Agent**, агент **IACPaaS Analyst**
(`.github/agents/iacpaas.agent.md`). Консоль – `.venv\Scripts\iacpaas-agent`, веб-чат – `.venv\Scripts\iacpaas-web`.
Ожидаемые значения посчитаны кодом напрямую из выгрузки базы (не из ответа агента).

| № | Сценарий ТЗ | Запрос | Ожидаемые вызовы | Ожидаемый результат |
|---|---|---|---|---|
| S1 | отбор + top-N | «Выдай три газа с наибольшими примесями аргона» | `gas_query(op="max", by="аргон", top=3)` | три водорода: второй сорт 0.002 %, первый 0.0002 %, высший 0.00002 %; сноски: 10 газов без состава, 35 без отдельного Ar |
| S2 | вопрос из трёх частей: «без», крайнее среди найденных, расчёт | «Какие аргоны без метана? Какой из них хуже всего по азоту? И во сколько раз кислорода в аргоне 4.8 больше, чем в аргоне 6.0?» | `gas_query(op="list", gases="аргон", without="метан")`, `op="max", by="азот"` среди трёх, `op="calc"` | 3 аргона (газообразный высший и первый сорт, жидкий высший); хуже – первый сорт, N 0.01 %; 0.0002 / 0.00003 = 6.67 |
| S3 | равенство на границе | «Какой кислород хуже всего по водяным парам?» | `gas_query(op="max", gases="кислород", by="водяные пары")` | **два** газа по 0.007 % («поровну у 2»); жидкий кислород – без водяных паров, в сноске |
| S4 | подсчёт вершин и дуг | «Сколько вершин и дуг в базе технологических газов?» | `count_graph` | 1478 вершин, 1479 дуг (2 ссылки, 749 терминальных) |
| S5 | запись с подтверждением в свою папку | «Добавь в мою папку аргоны» → «да»; «удали её» → «да» | `save_selection` без токена → предпросмотр → с токеном; `delete_from_fund` так же | новый ИР в «Загрузки/Песочница ИИ» (249 вершин, 248 дуг) только после «да»; удалён только после «да» |
| S6 | изменение выданной базы | «Удали аргон 6.0 из базы» | — (или поиск) | отказ: выданные ИР – только чтение; предложение сделать копию в свою папку |
| S7 | уточнения в длинной переписке | «Какие аргоны без метана?» → «а какой из них хуже всего по азоту?» → «Какие газы на основе кислорода?» → «Сколько вершин и дуг в базе газов?» → «Какие гелии есть в базе?» → «вернёмся к аргонам без метана – какой из них самый чистый?» → «а из них какие жидкие?» → «вернёмся к кислородам – какой из них хуже всего по водяным парам?» | `gas_query` в рамках газов того прошлого вопроса (иначе запрос исправляет код) | аргон первый сорт, N 0.01 %; 1478 / 1479; два аргона высшего сорта по 99.993 % (не гелий 7.0, не аргон 6.0); аргон жидкий высший сорт; два кислорода по 0.007 % |

### Результаты (10–11.11.2026)
- **Claude Code (VS Code):** S1–S6 верно. Найдено и исправлено: на вопросы о газах модель выводила метку `{{#c038}}`
  вместо ответа – подсказка `gas_query` для всех клиентов говорила «вставь метку», а подставляет куски только наш
  агент. Теперь `IACPAAS_PIECES=text` (по умолчанию, VS Code) – «перескажи answer дословно»; наш агент запускает
  сервер с `marks`. S6 – отказ и безопасная альтернатива (перезапись своей подборки без 6.0 через предпросмотр).
- **GitHub Copilot (агент IACPaaS Analyst):** S4, S6 верно; «удали с моей папки всё» – удалена только своя подборка,
  выданные ИР не тронуты, после предпросмотра и «да».
- **Консоль (GigaChat):** S1, S3, S4 верно, под ответом «✓ ответ собрал код из базы: N чисел»; запись и удаление –
  через «Разрешить? [y/N]»; `/compact` – первый вопрос назван верно и после сжатия.
- **Веб-чат (GigaChat):** S1–S3 и вопросы преподавателей («общие примеси водорода и аргона», «отсортируй по
  увеличению примесей метана», «состав аргона 4,8», «а из них какие жидкие?») – сверено скриптом по базе, верно.
- **Уточнения, S7 (GigaChat, 11.11):** до правки «а какой из них хуже по водяным парам?» после кислородов и
  «вернёмся к аргонам без метана – самый чистый?» модель считала по всей базе (водород В, гелий 7.0). Теперь к
  какому прошлому вопросу уточнение – решает код, газы ответа сверяются с газами того вопроса; ответ по данным –
  только куски кода. S7 целиком – все ответы верны (сверены с эталонами кодом).

## Демонстрация в VS Code: GitHub Copilot, режим Agent (ТЗ, разделы 7 и 9)
Подготовка: открыть папку `iacpaas-mcp-agent` как рабочую → `MCP: List Servers` → `iacpaas` → Start (сервер stdio
из `.mcp.json`) → в чате режим **Agent**, агент **IACPaaS Analyst**. Вызовы видны в чате (раскрыть шаг) и в
`logs/server.jsonl`. Данные — реальная платформа, только чтение.

| № | Сценарий ТЗ | Запрос | Ожидаемые вызовы | Ожидаемый результат |
|---|---|---|---|---|
| V1 | поиск ресурса → метаданные (два вызова подряд) | «На какой онтологии построена база технологических газов и какие в ней разделы?» | `list_inforesources` → `get_inforesource` | «Онтология базы технологических газов»; разделы Моногазы, Многокомпонентные газовые смеси |
| V2 | подграф с ограничением глубины + подсчёт вершин и дуг | «Покажи газы на основе аргона с глубиной 1 и посчитай вершины и дуги раздела „Моногазы“» | `get_subgraph(root="Моногазы/Газы на основе Аргона", depth=1)` → `count_graph(root="Моногазы")` | 6 газов; 1465 вершин, 1464 дуги |
| V3 | некорректный идентификатор + превышение лимита размера | «Открой ИР „Загрузки/База технолоческих газов“ и выгрузи её целиком в JSON» | `get_inforesource` / поиск → `export_json` → `[too_large]` | «точного нет, вероятно „База технологических газов“»; 198 930 символов > 60 000; влезает «Многокомпонентные газовые смеси» |
| V4 | тот же сценарий в standalone-агенте | V2 в консоли (`iacpaas-agent`) или веб-чате (`iacpaas-web`), GigaChat | те же вызовы | те же числа — сравнить с ответом Copilot |
| V5 | изменяющая операция с обязательным подтверждением — **на платформе, в своей папке** | тот же агент **IACPaaS Analyst**: «Сохрани в мою папку подборку „Газы на основе аргона“ — все газы этого класса, с пометкой у газов без состава» → после предпросмотра «да»; затем «Удали эту подборку» → «да» | `gas_query(op="list", gases="аргон")` / `check_inforesource` → `save_selection` без токена (предпросмотр) → [«да»] → с `confirm_token` → `get_inforesource`; `delete_from_fund` ×2 | предпросмотр: новый ИР «Загрузки/Песочница ИИ/…», 6 газов, пометки; Copilot дополнительно спрашивает разрешение на изменяющий инструмент; после «да» — ИР на платформе (виден на сайте); при «нет» — ничего |

Запись — только в `Загрузки/Песочница ИИ` (`IACPAAS_WRITE_PATHS`): попытка изменить выданную базу даёт
`[read_only]` ещё до предпросмотра, агент предлагает сохранить копию в свою папку.

### Результаты
- **V1–V5 на газах (18.10.2026, Copilot Auto → GPT-6 Luna + веб-чат GigaChat):** V1 — онтология и 2 раздела;
  V2 — 6 газов аргона, «Моногазы» 1465 / 1464; V3 — опечатка найдена, 198 930 символов больше лимита (Copilot
  вдобавок сам выгрузил базу в компактном `simple`, он в лимит укладывается — допустимо); V4 — веб-чат на
  GigaChat дал те же числа; V5 — подборка «Газы на основе аргона» (6 газов, 249 вершин) создана на платформе в
  «Песочница ИИ» после предпросмотра и подтверждения, затем удалена кнопкой в веб-чате. Всё верно.
- **V5, первая версия (14.10.2026, Copilot, песочница в памяти):** два уровня подтверждения — Copilot спрашивает
  «Разрешить инструмент: Изменить вершину?», затем предпросмотр нашего сервера и «да». Найденная ошибка (токен выдавался
  на неверный `metaconcept_path`) исправлена — сервер проверяет аргументы уже на предпросмотре. С 18.10.2026 V5 —
  на платформе, в своей папке (сервер-песочница убран): повторить.
- **V1–V4:** первый прогон 14.10.2026 был на прежнем ИР (математика, `docs/dev-log.md`, этап 11) — все верно, а
  найденная в V4 ошибка (числа «в пределах depth» в `get_subgraph`) исправлена в сервере. На ИР газов — повторить.
